# VIRTUAL-MATERIALS-PANEL

3D web application for approved automotive materials (Renault) - developed to optimize complex material selection processes within engineering. 
This application uses the threeJS library to render an interactive vehicle model for selecting vehicle parts and providing key information for better decision-making.

Demo version without confidential data available.
